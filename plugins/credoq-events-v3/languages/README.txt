Translation files for credoq-events.

Generate a .pot file with WP-CLI from the plugin root:
  wp i18n make-pot . languages/credoq-events.pot --domain=credoq-events

Then translate with Poedit (or any gettext editor) into
languages/credoq-events-{locale}.po / .mo, e.g. languages/credoq-events-fr_FR.po
