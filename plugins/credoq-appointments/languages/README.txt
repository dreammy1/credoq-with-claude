Translation files for credoq-appointments.

Generate a .pot file with WP-CLI from the plugin root:
  wp i18n make-pot . languages/credoq-appointments.pot --domain=credoq-appointments

Then translate with Poedit (or any gettext editor) into
languages/credoq-appointments-{locale}.po / .mo, e.g. languages/credoq-appointments-fr_FR.po
