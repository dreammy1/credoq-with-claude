Translation files for credoq-membership.

Generate a .pot file with WP-CLI from the plugin root:
  wp i18n make-pot . languages/credoq-membership.pot --domain=credoq-membership

Then translate with Poedit (or any gettext editor) into
languages/credoq-membership-{locale}.po / .mo, e.g. languages/credoq-membership-fr_FR.po
